# 🎵 SoundToMidi - Музыкальный транскрайбер

Программа для преобразования аудиофайлов в MIDI ноты с автоматическим определением темпа и настройкой чувствительности.

## ✨ Возможности

- 🎵 Автоматическое распознавание нот из аудиофайлов
- ⏱️ Автоматическое определение темпа (BPM)
- 🎚️ Настройка чувствительности распознавания
- 📊 Определение длительности нот
- 📈 Визуализация результатов
- 💾 Сохранение в MIDI формат
- 🎹 Определение типа нот (целая, половинная, четвертная и т.д.)

## 📋 Требования

- Python 3.8 или выше
- Установленные зависимости из `requirements.txt`

## 🚀 Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/ВАШ_ЛОГИН/SoundToMidi.git
cd SoundToMidi

# Установите зависимости
pip install -r requirements.txt

# Запустите программу
python music_transcriber_app.py
